# Spending and credits report

Generate a comprehensive spending and credits report. Follow these steps:

1. Use get_credits_balance to check the current available credits.
2. Use get_spending_summary to get spending for the current month.
3. Use get_agents_usage to identify which agents are costing the most this month.
4. Use get_credit_history to retrieve recent credit transactions (additions and deductions).
5. Summarize the findings: current balance, total spent this month, top-cost agents and notable transactions.
